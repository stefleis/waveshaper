# Waveshaper Audio

Static portfolio site for www.waveshaper.dk. Plain HTML/CSS/JS, no build step.

- **Add or reorder projects:** edit `js/projects.js`. Put the thumbnail in `images/` and the clip in `videos/` (or set `youtube` to a YouTube video id instead of `video`).
- **Preview locally:** `python -m http.server` in this folder, then open http://localhost:8000.
- **Deploy:** push to a GitHub Pages / Netlify site and point the `waveshaper.dk` DNS at it.
